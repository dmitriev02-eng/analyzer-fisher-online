# FisherLogger Companion (Android)

Android-компаньон для FisherLogger. Работает **только на чтение**. Сервера в интернете нет: телефон подключается к FisherLogger на ПК в локальной сети Wi-Fi/LAN.

## Где что лежит

| Что | Путь |
|---|---|
| Проект Android Studio | `D:\TheFisherProject\Android\FisherCompanion\` |
| Отладочный APK | `D:\TheFisherProject\Android\apk\FisherCompanion-0.1.0-debug.apk` (копия `app\build\outputs\apk\debug\app-debug.apk`) |
| Инструменты сборки (JDK 17, Android SDK 34, Gradle 8.9) | `D:\TheFisherProject\Android\toolchain\` — портативные, в систему не устанавливались |
| Сервис на стороне Windows | `D:\TheFisherProject\App\src\CompanionServer.cs` + кнопка «Телефон» в `Form1.cs` |

Технологии:
- Kotlin 2.0.20, Jetpack Compose (BOM 2024.09.03), Material 3, AGP 8.5.2;
- minSdk 26 (Android 8.0), targetSdk 34.

## Сборка

```powershell
$env:JAVA_HOME='D:\TheFisherProject\Android\toolchain\jdk17'
$env:ANDROID_HOME='D:\TheFisherProject\Android\toolchain\sdk'
```

## Установка на телефон

  `D:\TheFisherProject\Android\toolchain\sdk\platform-tools\adb.exe install -r D:\TheFisherProject\Android\apk\FisherCompanion-0.1.0-debug.apk`
- **Вручную:** скопировать APK на телефон и открыть его. Понадобится разрешить установку из этого источника.

## Подключение и сопряжение

1. Телефон и ПК должны быть в одной сети.
2. В FisherLogger нажмите **«Телефон: выкл»** (правый верхний угол), затем **«Включить сервис»**. Сервис по умолчанию выключен и после перезапуска FisherLogger снова выключен.
3. При первом включении Windows может спросить разрешение брандмауэра. Разрешите **только «Частные сети»**.
4. В том же окне показан адрес для телефона, например `192.168.3.4 : 47811`.
5. В приложении на телефоне откройте вкладку **«ПК»**, введите IP и порт, нажмите **«Проверить связь»**.
6. В FisherLogger нажмите **«Создать код сопряжения»**: появится 6-значный код, он действует 2 минуты и один раз. Введите код на телефоне и нажмите **«Сопрячь»**.
7. Отозвать доступ: окно «Телефон» → выбрать устройство → **«Отозвать выбранное»**.

## Безопасность

- **Только локальная сеть.** Подключения принимаются только с частных адресов, остальные закрываются без ответа: 127/8, 10/8, 172.16/12, 192.168/16, 169.254/16, fe80::/10, fc00::/7.
- **Сопряжение.** Используется обмен ключами ECDH P-256. Код сопряжения (через PBKDF2-SHA256, 100 000 итераций) подтверждает обмен с обеих сторон. Общий секрет по сети не передаётся. После 5 неверных кодов код аннулируется.
- **Подпись запросов.** Каждый запрос подписан HMAC-SHA256: метод, путь, время (±120 с) и одноразовое число. Повтор того же запроса отклоняется. Ответ ПК тоже подписан, телефон проверяет подпись.
- **Защита от перебора.** После 20 неудачных запросов за минуту адрес блокируется на 5 минут.
- **Хранение секрета.**
  - ПК: Windows DPAPI (текущий пользователь), файл `%LOCALAPPDATA%\FisherLogger\companion_settings.json`.
  - Телефон: шифрование AES-GCM ключом из Android Keystore; резервное копирование данных приложения отключено.
- **Только чтение.** API отвечает только на GET; запрос на сопряжение — единственный POST. Базы открываются в режиме `Mode=ReadOnly`, в коде сервиса нет ни одной записи в базу.
- **Ограничение — шифрования трафика нет.** Связь идёт по HTTP. Подписи защищают от подмены и чужого доступа, но данные (уловы, аналитику) можно прочитать, перехватывая трафик в той же сети.

## API (только чтение)

| Метод | Путь | Что отдаёт |
|---|---|---|
| GET | `/api/ping` | Проверка связи и время ПК (без авторизации, без данных) |
| GET | `/api/pair/hello` | Начало сопряжения (только пока действует код) |
| POST | `/api/pair` | Сопряжение |
| GET | `/api/status` | Игровое время (оценка, модель, погрешность), текущий водоём, последняя погода s2c1001 |
| GET | `/api/options?scope=all\|current` | Виды, водоёмы, диапазон дат |
| GET | `/api/analytics?...` | Тот же `AnalyticsEngine`, что окно «Аналитика» в Windows, включая текст сводки и пояснений |
| GET | `/api/catches`, `/api/public` | Мои уловы и объявления |
| GET | `/api/maps`, `/api/maps/{id}/image`, `/api/maps/{id}/points` | Реестр карт; изображение (только при совпадении SHA-256 с реестром); точки по `MapDataLoader` |

## Версия 0.2.0 (NEXT-ANDROID-02): зоны активности и батиметрия

Новые эндпоинты API (только чтение, подписанные):

| Метод | Путь | Что отдаёт |
|---|---|---|
| GET | `/api/bathymetry` | Статус батиметрии всех 36 водоёмов, легенда, подписи изобат, достоверность |
| GET | `/api/maps/{id}/bathymetry` | Слой глубин PNG 2048² (та же рамка, что у карты; отдаётся только при совпадении SHA-256 с реестром) |
| GET | `/api/maps/{id}/depth?x=&z=` | Глубина дна в точке, м (сетка 1024²) |
| GET | `/api/maps/{id}/zones?scope=&species=&from=&to=&unverified=` | Зоны активности (`ActivityZones`, тот же код, что в Windows) и отфильтрованные точки |

- Данные батиметрии: `D:\TheFisherProject\Data\assets\bathymetry\`; генератор — `build_bathymetry.py` в той же папке.
- Глубина = уровень воды сцены − высота рельефа TerrainData, в метрах.
- Зоны — это мои записанные уловы в точках заброса. Это не вероятность клёва. У объявлений других игроков координат нет.
